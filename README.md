# Sistema de Gestão Académica Simplificado

## 1. Descrição do Projeto

O Sistema de Gestão Académica Simplificado é uma aplicação desenvolvida no âmbito da unidade curricular de programação.

O projeto pretende facilitar a gestão de informação académica, permitindo organizar dados de estudantes, unidades curriculares, avaliações e classificações.

## 2. Problema

A gestão de estudantes, classificações e informação académica exige organização e controlo dos dados. A ausência de um sistema centralizado pode dificultar a consulta e atualização dessas informações.

## 3. Objetivos

- Desenvolver uma aplicação de gestão académica.
- Organizar os dados dos estudantes.
- Gerir unidades curriculares.
- Registar avaliações e classificações.
- Calcular médias académicas.
- Apresentar estatísticas sobre o desempenho dos estudantes.

## 4. Funcionalidades Previstas

- Registo, consulta, edição e eliminação de estudantes.
- Gestão de unidades curriculares.
- Associação de estudantes às unidades curriculares.
- Registo de avaliações e classificações.
- Consulta de notas e cálculo de médias.
- Apresentação de estatísticas académicas.

## 5. Tecnologias Utilizadas

- **Python:** linguagem de programação utilizada no desenvolvimento.
- **SQLite:** sistema de gestão de base de dados.
- **Tkinter:** biblioteca utilizada para desenvolver a interface gráfica.

## 6. Organização do Projeto

O projeto será organizado em diferentes módulos, de forma a separar a interface gráfica, a lógica da aplicação e a gestão da base de dados.
