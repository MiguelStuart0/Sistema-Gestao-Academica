# Sistema de Gestão Académica Simplificado

## Descrição
Aplicação destinada à gestão de estudantes, unidades curriculares, avaliações, classificações e estatísticas académicas.

## Problema
A gestão de informação académica exige organização e controlo dos dados. Este sistema pretende simplificar esse processo.

## Objetivos
- Gerir estudantes.
- Gerir unidades curriculares.
- Registar avaliações e classificações.
- Consultar resultados académicos.
- Calcular médias e apresentar estatísticas.

## Funcionalidades
1. Gestão de estudantes.
2. Gestão de unidades curriculares.
3. Gestão de avaliações.
4. Gestão de classificações.
5. Estatísticas académicas.
