Descrição do Problema

A gestão de informação académica envolve vários dados, como estudantes, unidades curriculares, avaliações e classificações. Quando estes dados não estão devidamente organizados, a sua consulta e gestão podem tornar-se difíceis.

Este projeto pretende desenvolver uma aplicação que facilite a organização e a gestão dessas informações num único sistema.

Objetivos do Projeto

  • Facilitar a gestão de estudantes.
  • Organizar as unidades curriculares.
  • Registar avaliações e classificações.
  • Permitir o cálculo de médias.
  • Disponibilizar estatísticas académicas.
  • Desenvolver uma interface simples e intuitiva.

Funcionalidades Planeadas

  • Adicionar, consultar, editar e remover estudantes.
  • Gerir unidades curriculares.
  • Registar avaliações e classificações.
  • Calcular médias dos estudantes.
  • Consultar estatísticas académicas.
  • Utilizar uma interface gráfica para gerir os dados.
Estado do projeto: Em desenvolvimento. As funcionalidades serão disponibilizadas progressivamente.

Tecnologias Utilizadas

  • Python: linguagem de programação.
  • SQLite: gestão da base de dados.
  • Tkinter: desenvolvimento da interface gráfica.
  • GitHub: organização e controlo do projeto.

Manual de Utilização

O manual de utilização será atualizado à medida que a aplicação for desenvolvida.

  1. Iniciar a aplicação no ambiente Python.
  2. Aceder às opções disponíveis na interface gráfica.
  3. Selecionar a funcionalidade pretendida.
  4. Introduzir ou consultar os dados académicos.
Estes passos são indicativos. O manual definitivo será concluído após a implementação da aplicação.
